The project overview is your starting point after setup. Your project name and website identify the workspace, while the date selector switches between the last **7 days** and **30 days**. Reporting uses UTC.

## Read the overview

The summary includes daily unique visitors, page views, API requests, and API latency at the 95th percentile. Traffic charts and breakdowns are arranged below, alongside a connection summary.

New projects have no collected activity. A dash indicates that a source is not connected; it should not be read as zero usage.

## Check your connections

Choose **View connections** to inspect the sources selected during setup. Read [Data sources](/data-sources) to understand their status. Overview is the currently available dashboard page; the additional analytics and settings sections are not available yet.
