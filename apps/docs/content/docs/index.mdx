Lumen Radar brings website activity and API usage into one workspace for Stellar projects. It is being built to help teams understand adoption, follow usage trends, and see how their services are used.

## One project, two signals

**Web analytics** focuses on visitors, page views, popular pages, and traffic sources. **API analytics** focuses on request volume, response status, and latency.

A project gives these two signals a shared home. Start by adding your project details, then choose website analytics, API analytics, or both.

## Where to begin

Follow [Getting started](/getting-started) to create your workspace, then explore the [project overview](/project-overview).

Lumen Radar is in active development. Project setup is available today; live data collection is not connected yet. New workspaces begin with empty reports.
