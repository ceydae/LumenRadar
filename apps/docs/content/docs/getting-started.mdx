Open **Dashboard** in the header to begin. Use the sign-up or sign-in screen, then continue through the two setup steps. The current dashboard keeps your workspace in this browser; it does not yet provide server-backed accounts.

## Add your project

Enter a project name, a full website URL, and a short description of how your project uses Stellar. Choose **Continue to data sources** to save these details.

## Choose what to measure

Select **Website analytics**, **API analytics**, or **Both**. If you include API analytics, add an API service name. Choose **Open workspace** to reach your project overview.

Selecting a source prepares your workspace; it does not start collecting activity. See [Data sources](/data-sources) for the meaning of each connection status.
