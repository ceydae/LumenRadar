During setup, choose the sources that fit your project. **Website analytics** represents activity on your site. **API analytics** represents requests to your service and asks for a service name. **Both** prepares the workspace for the two sources together.

## Understand source status

The dashboard distinguishes three states:

- **Not selected** — this source was not included during setup.
- **Awaiting data** — the source is selected, but no activity has arrived.
- **Connected** — the source has an active connection.

## Selection comes first

Current workspaces remain at **Awaiting data** for selected sources. Live collection and the tracking integration are still in development, so selecting a source does not connect your website or API automatically.

Return to [Project overview](/project-overview) to see where source status appears in the dashboard.
