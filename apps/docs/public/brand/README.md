# Lumen Radar artwork

Official source: `apps/Lumen_Radar_Brand_Kit`.

- `symbol-navy.svg` / `symbol-white.svg`: the stepped-L paths from
  `02_Symbol/lumen-radar-symbol-{navy,white}.svg`, with the viewBox trimmed
  to `58 58 559 641`, as used by the dashboard.
- `wordmark-navy.svg` / `wordmark-white.svg`: the paths from
  `01_Logos/lumen-radar-wordmark-{navy,white}.svg`, with the viewBox trimmed
  to `96 96 1743 143`, as used by the dashboard.
- Favicons and Apple touch icon in `public/` are the official `04_Favicons` exports.

Only export whitespace is removed. Paths, colors, and proportions are preserved.
The landing header uses the kit's primary horizontal logo; the docs use the
dashboard's separate symbol and wordmark so the artwork stays legible at header size.
